==============================================================================
  ① 最小启动与远程访问
==============================================================================

  先在 ComfyUI 根目录把这节跑通，其余参数都加在它们后面。

  ▸ 最小启动
    $ python main.py
    只听 127.0.0.1:8188，只有本机能开。
    虚拟环境里把 python 换成 venv/bin/python（Windows 是 venv\Scripts\python.exe）。

  ▸ 换端口
    参数：--port 8189
    8188 被占了就换。端口只管听哪个口，能不能从外面连取决于 --listen。

  ▸ ★ 允许外部访问（远程 / 云平台必加）
    参数：--listen 0.0.0.0 --port 8188
    默认只听本机，局域网和公网都连不上。
    ⚠ 等于把这个口暴露出去，公网务必用安全组限制来源 IP。

  ▸ 前端被跨域拦住时
    参数：--listen 0.0.0.0 --enable-cors-header
    放行跨域（默认 "*"）。只有入口页面和 API 不同源时才需要。

  ▸ 启动后自动开浏览器
    参数：--auto-launch
    桌面机省一次点链接；远程/无头机器上没用。

==============================================================================
  ② 显存自救
==============================================================================

  二采 OOM 先加第一条。启动参数改完必须重启才生效。

  ▸ ★ 多留 1GB 显存（二采 OOM 首选）
    参数：--vram-headroom 1
    让 DynamicVRAM 额外空出 1GB，权重会被更早换出去。
    这是每设备预留，进程一起来就定死；不想重启就改面板「性能优化 → 显存预留（GB）」，它写的是进程级那一项。

  ▸ 还炸就留 2GB
    参数：--vram-headroom 2
    余量更大，代价是更多块要来回搬 —— 慢得也更明显。

  ▸ 关掉 Comfy 编译器（1GB 还不够时）
    参数：--disable-comfy-compiler
    显存占用从接近 100% 降到 ~77%，代价约 5% 耗时。

  ▸ 不缓存节点结果（最省内存）
    参数：--cache-none
    每次执行都重算，换来更低的主机内存峰值。

==============================================================================
  ③ Linux 后台运行
==============================================================================

  云平台上断开 SSH 就停的话，用这三条。

  ▸ 脱离终端跑
    $ nohup python main.py --listen 0.0.0.0 --port 8188 > comfyui.log 2>&1 &
    关掉 SSH 也不退；日志落盘，出问题还能翻。

  ▸ 看实时日志
    $ tail -f comfyui.log
    模型加载与 OOM 都在这行里。

  ▸ 停掉它
    $ pkill -f "python main.py"
    按命令行匹配杀进程；改完启动参数要重启时用。
