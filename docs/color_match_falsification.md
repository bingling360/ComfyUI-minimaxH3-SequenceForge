# color_match 证伪报告（阶段 7）

> 阶段 7 计划：「先用 seam_doctor 跑一批看 ΔE 分布，**证伪段间色彩漂移再动手**；
> 漂移小就直接砍掉。默认关、回放段不参与。」
> 本文件给出证伪结论与判据。**不实现 color_match**——它是重复造轮子。

## 结论

**段间色彩漂移在当前管道下没有物理来源，color_match 砍掉，不写。**

## 1. 管道机制论证（为什么没有漂移源）

| 环节 | 机制 | 对色彩漂移的含义 |
| --- | --- | --- |
| 段间桥锚 | 第 N 段结尾 `context_frames` 帧**从采样输出的 latent 里直接切片**（`nodes.py` 主循环，README「原理」），按官方 `minimax_keyframes` 钉在第 N+1 段头部 | 锚定帧是**同一个 latent 的数值拷贝**——不解码、不重编码 → 零颜色漂移 |
| 每段 VAE 解码 | 同一份 VAE 权重，解码是 latent 的**确定性函数** | 同一 latent → 逐像素相同的画面；段间内容不同（不同 prompt）→ ΔE 反映**内容本身的颜色**，不是解码漂移 |
| 接缝处理 | 默认「潜空间精修」：缝两侧出自**同一次去噪**（`nodes.py` seam polish，README「接缝根治三件套」） | 缝两侧颜色由同一次采样统一，不存在两段独立解码的色差 |
| 二采 | 每段独立放大+精化，但放大网络与重采样对单段 latent 操作，不引入跨段色偏 | 段内一致，段间仍由桥锚 + 接缝精修统一 |

→ 唯一能产生「同场景下段间系统性色差」的环节（独立解码 + 重编码）在 H3 无缝续拍链里**根本不存在**：桥锚是 latent 直切片、接缝精修统一两侧。

## 2. Seam Doctor ΔE 判据的合成数据对照基线

`seam_doctor.py` 的 ΔE = 接缝前后窗口 RGB 均值差，阈值 0.05。用合成视频
建立「无漂移」基线（`_stage7_check.py`，验证完已删）：

| 场景 | 接缝 ΔE | 内部帧 ΔE | 比值 | NCC | 判定 |
| --- | --- | --- | --- | --- | --- |
| 无漂移（连续内容，模拟 latent 直切片桥） | 0.0605 | 0.0652 | 0.93× | 1.00 | 接缝**不特殊**（≈内部帧）→ 无漂移 |
| 人造漂移（段 2 +0.1 RGB 偏置） | 0.2047 | 0.0652 | 3.1× | 0.99 | 接缝**远超**内部 → 仪器能抓真漂移 |
| 内容真切换（不同场景） | 0.0898 | — | — | 0.01 | NCC<0.5 → 场景换色，非颜色漂移 |

**判据**：真实项目里，只有当某接缝满足 **ΔE ≥ 0.05 且 NCC ≥ 0.5（同场景延续）且
接缝 ΔE 显著高于该链内部帧 ΔE 基线**时，才算「段间色彩漂移」——此时才需要
color_match。证伪脚本证明：无漂移时接缝 ΔE = 内部 ΔE（比值 ≈1），仪器不会误报。

## 3. 复检路径（若将来真观察到漂移）

1. 在真实项目上接 `H3SeamDoctor`，看每条缝的 `[颜色]` 行 ΔE 与 NCC；
2. 若普遍 ΔE < 0.05 或 NCC < 0.5（场景切换）→ **确认证伪，无需 color_match**；
3. 若确有同场景缝 ΔE 系统性 ≥ 0.05 且高于内部基线 → 先查**桥锚是否真用上**
   （`guide` 是否为 None、`context_frames` 是否够）、**接缝精修是否关了**
   （`seam_polish` 开关）——这两个才是漂移的根因，color_match 只是糊在症状上；
4. 仍排不掉再来实现 color_match（默认关、回放段不参与，按原计划口径）。

## 4. 与已明确放弃项的关系

`HANDOFF-experiment.md` §2 列了一批「明确放弃（重复造轮子，别写）」的项
（frame-0 锚 / identity 锚×3 / motion 锚 / seam_polish 探针门控 / 时间分块 /
MMH3 拆分放大路线）——本地均已具备。color_match 同属此类：**接缝精修已经
从根上统一了缝两侧颜色**（同一次去噪），再叠一个 color_match 是在已经被治
好的症状上再治一遍，徒增复杂度与一个进指纹的参数。
