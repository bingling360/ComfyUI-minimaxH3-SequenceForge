# 改动总结：横向分段 + 具象化精简 + 优化面板对齐

分支：`experimental-branch-2`（基于 `3886f87`）

## 一句话

中部提示词区改为**顶部横向分段条（点选看一段，pill 可拖调序）**，状态条压 slim；
插入视频前端彻底删除（后端保留）；具象化精简为 **FL2VA / Ref2VA 两模式**且界面全中文化
（显示中文、存英文，后端输出英文不变）；优化设置面板结构对齐参考项目。

## 1. 状态条瘦身（`web/h3_director.js`）

- `statusLine()` 文案缩短：`段 N/M 已完成 · 将生成段 K` / `共 M 段 · 待生成段 1` / `✓ M/M 已完成`
  （去掉“已载入段 1–N（存档回放）→ …”大横幅）。
- `.h3d-statusbar` 压成单行小字条（11.5px），按钮同步缩小。

## 2. 横向分段条 + 单卡（`web/h3_director.js`）

- 新增 `renderSegStrip()`：`段1 段2 … ＋` 横向 pill，`flex:1 1 0 + min-width:44px`
  先压缩、极限后横滑；pill 带状态点（已完成/下一段/🔗独立/⏸禁用），`＋` 横向加段并自动选中。
- 中部只渲染选中段一张卡（`buildCards` 跳过非选中段）；选中态 `_selSeg` 纯内存，
  不落 ds、不触发重做，进 `cardsSignature` 签名。
- 删除：卡片把手 `⠿`、`⬆⬇` 按钮、卡片级纵向拖放（`nudgeIns` / `dropIndexAt` / `setDropLine`
  改为 strip 横向版 `dropPillIndexAt` / `setPillDropLine`）。
- 排序：pill 上拖动，复用 `reorderChain` / `applyReorder`（含范围清重摇/二采），选中跟随被拖段。
- 增删联动：`addPromptSegment` 新增即选中；`removePromptSegment` 越界钳位，删空回单空段。

## 3. 插入视频前端彻底删除（后端保留）

- 删除：链尾/段间插入按钮、插入卡片、移除入口；`appendInsert` / `pickInsertVideo` /
  `removeInsert` / `insertButton` 改为废弃 stub（防残留调用报错）。
- `planFromDs()` 只排提示词段；`getDs` 解析、`setDs` 写回、落盘里的 `ds.inserts` 全保留，
  旧项目数据不丢失。后续 latent 注入框架在分段设置里重做。

## 4. 具象化：两模式 + 手动覆写

- `V2_MODES = ["FL2VA", "Ref2VA"]`；默认跟随导演台（多参→全参考，其余→首尾帧，
  无帧时 FL2VA 编译退化为纯文本三字段，与 T2VA 等效）；手动下拉存 `seg.v2mode`
 （null=自动），随 ds + manifest 持久化（`projects.py` 白名单已加，
  旧存档的 T2VA/I2VA/L2VA 自动回落为跟随）。
- 面板头显示生效模式 + 自动/手动徽；base 系显示对齐指令预览，Ref2VA 显示六段式提示；
  参考组仅 Ref2VA 挂载，内部按官方顺序（主体→引用→总结→保留分析），任务类型 6 快捷按钮。
- 后端（`prompts.py` / `routes.py`）：`compile_segment` 加 `mode` 手动参数
  （非法回退自动 + `W_MODE_OVERRIDE` 警告），`/h3chain/compile` 透传；
  summary 任务类型连接符按官方改为 ` + `。`VALID_MODES` 五个全保留，前端只开放两个入口。
- 三处编译调用（预览/同步到主框/从具象化同步）均带 `mode`；“从具象化同步”顺手修复了
  写死的 `has_start/end=false`，改为按实际首尾帧计算。
- 预留 `H3Prompts.assignV2FromText` 占位钩子（后续自动解析分配接口）。

## 5. 具象化全中文化（显示中文 ⇄ 存储英文）

- 标签/按钮/分组全中文；官方字段名只放括号对照；运镜 20 词、幅度/速度、说话人
  （说话人1↔S1）、语言（中文↔Chinese）、任务类型、保留关系、模式选项全部
  “显示中文、存英文”（`mkMapSel` + `zh/en` 六组互转函数）。
- 保留英文的三处（内容非说明）：对齐指令预览行、输入框 `例：` 英文示例、编译结果头 `[FL2VA]`。
