# 改动总结：资产库架构重构（无模式链路 + 三库面板 + 转码内联）

分支：`experimental-branch-2`

## 一句话

项目文件夹收敛为 **assets / finals / latent / texts 四库**（`manifest-v2.2`，旧裸名双路径兼容）；
删除手动模式选择，链路由后端按实际引用自动推导（证据：官方无 UNET 校验、单 DiT 架构）；
资产库成为纯库（总量不限、打标、入库拷贝、行内剪辑/转码）；引用分书写/调度/锚定三层归位；
转码从镜像节点改为**主节点内联短路执行**；修掉转码卡死与本轮报障的一批 bug。

## 1. 项目四库规范（`checkpoint.py` / `projects.py`）

- `ensure_project_dirs` / `resolve_project_file`：新产物进 `finals/`（段/成片/合并/缩略图）、
  `latent/`、`texts/（prompts_latest.json）`；旧根目录裸名双路径兼容读，不主动搬家。
- `MANIFEST_SCHEMA → v2.2`；`create_project` / `ckpt_dir` 自动建四目录。
- `trim_asset` 产物落源文件同库；`merge_project` / `_autosave_final` / 二采成片全部收进 `finals/`；
  `upscale_files` 改 `finals/` 前缀，`_record_valid` / `try_final` 双路径兼容。
- 主循环 manifest 全量覆写携带三库键（修了旧的“跑一次链冲掉 assets/latents/clips”丢键 bug）。
- `delete_file` 路由放行四级路径（`h3_projects/<项目>/<库>/<文件>`）。

## 2. 三库 ops 与互斥（`projects.py` / `routes.py` / `checkpoint.py`）

- 新增 `move_media`（assets↔finals 搬家 + manifest 全表改写不断链 + 可选登记标签）、
  `split_av`（画面 mp4 + 音频 wav）、`import_asset`（input 拷贝进 `assets/`，重名加后缀，登记 manifest）、
  `slice_latent kind=av/video/audio` 分开存。
- 生成互斥锁：`checkpoint.mark/unmark/is_busy`，主节点 `execute` 外壳置位，
  trim/slice/move/split 遇忙回 423，前端置灰 + 横幅（`GET /h3chain/busy`、`H3Latent.isBusy`）。
- 新增 `POST /h3chain/probe`（只读元数据：fps/frames/duration/尺寸/有无音轨）与 `media.probe_media`，
  供裁剪子面板填帧窗；`DELETE`/`merge` 等长耗时仍走线程池。
- `POST /h3chain/import_asset` 不受生成锁影响（纯文件拷贝，随时可用）。

## 3. 无模式链路自动推导（`nodes.py`）

- **证据**（已查官方实现）：`ImageToVideo` / `ReferenceToVideo` 只是 conditioning 构造器，
  零模型校验；采样 DiT 是同一套 `MiniMaxH3Model`，`supported_models` 只有一个 `MiniMaxH3`
  配置——fl2va/ref2va 之分只在权重文件。fl2va 跑多参机械可跑，效果看权重。
- 删除全部 5 条模式互斥报错；`生成模式` 控件留占位不再读取（旧工作流兼容）。
  有有效引用即走 ref conditioning；首帧可与引用共存（头锚 keyframe 叠加）。
  均匀链 `chain` 指纹与旧版逐字一致，旧项目续跑不断档。
- 缺省引用 = 只用提示词文本 `[[标签]]` 出现的素材（库再大也不逼勾选）；
  素材按段按需加载（引用并集，每标签全链解码一次；未引用文件不碰不占显存），
  报告注明跳过数；缺文件只对真引用它的段早爆点名。
- 资产 `roles: [首帧图/尾帧图]`：各只留一张（多标报错点名），仅图片可标；
  链首/链尾锚来源 = 标注资产（旧三槽位有值则优先，旧链零变化）。
- 段 `tail_src: {asset} | {latent}` 统一尾锚（替代旧全局每段尾帧锚定；FL2VA 终点段仍优先尾帧图），
  进段哈希；旧 `ds.last_frame` 兼容回退。
- `latent_ref.src` 外源桥保留（形状校验失败回落上段尾并注记）。

## 4. 前端（`web/h3_director.js` 等）

- 左栏素材池面板删除，并入三库资产页；模式条删除（链路页改为只读自动推导说明）。
- 右栏：📐基础设置 + 🔗视频延续（📌关键帧/🩺检测重摇两子折叠）；段卡设置页双按钮
  （自动引用上段/自动按序生成）+ 本段 latent 引用/保存 + `tail_src` 选择器。
- 统一引用条（tab 外常驻）：chip 亮绿=本段已调度，点按切换（可取消）；
  主框下打开调度顺手补 `[[标签]]`，具象化下同步加参考条目，标注徽标与资产库一致。
- 调度 chips（含 933 计数）迁入具象化参考组“分段素材调度”；`defaultV2Mode` 改按实际引用判定。
- 资产页：roles 开关（仅图片行）、上传即入库、旧池文件一键入库、旧三槽一键导入打标、
  裁剪/转码行内子面板（帧窗/秒窗+分支）、转码任务队列区（加入/移除/清理/清空/中断队列）、
  本库剪辑片段区；成片页 clips 按库分区、wav 行 audio 播放、操作转圈不锁面板。
- `ds.ref_assets` 与项目 `manifest.assets` 双向绑定：切项目即换池；删卡/改名/改标自动落盘。
- `getDs` 透传 `roles` / `tail_src`；模板说明同步去模式化。

## 5. 转码卡死修复 + 内联（`latent_tools.py` / `media.py` / `nodes.py`）

- 根因：整文件全解码进内存 + 整窗单次 VAE 前向（H3 训练长度 124–362 帧）+ 零进度。
- `media.decode_av(path, start_f, end_f, fps)`：深窗口 seek + 帧 pts 精确定位 + 到窗末早停；
  旧全量调用兼容不变（桩验证：起止精确、无 seek 误跳）。
- `MAX_ENCODE_FRAMES = 362`：`H3MediaToLatent` / `H3LatentExtract` 超限直接报错指引缩窗；
  解码本身也有界（最多读上限+1 帧，到片尾模式不再全片进内存）；四步进度条 + 终端打印。
- `H3LatentUpscale`：源超 720 帧拒收 + 进度打印。
- 镜像节点方案废弃：`ds.transcode_jobs` + 主节点 `_execute_transcode_only` 短路专跑
  （只跑转码不跑链不耗种子，任务间隙响应队列中断，产物登记 latent 库，前端凭证据自动清理）。
  `run_transcode_job` 纯函数供节点与主节点共用；模板镜像节点已移除（两模板恢复 32 节点/33 边）。

## 6. 本轮报障修复对照

- 素材「`assets/seg_000 (1).mp4`」报缺失：`asset_check` 只查 input → 现按项目解析
  （`assetCheck` 传 dir），文案区分项目文件夹/input 目录；空格括号文件名本就合法。
- 分段默认绿 + 不能取消：chips 改调度态显示 + 点按切换。
- 资产库跨项目共享：切项目绑定 `manifest.assets` + 改动自动落盘。
- 首尾帧标注出现在音视频行：仅图片行可标 + 后端 kind 校验。
- 分离音频去向：本库 clips 区 + audio 播放器 + op 徽标。
- 裁剪去成片库：产物落源文件同库 + clips 按库分区展示。

## 7. 接口变更表

- 新增节点：`H3MediaToLatent`（库转存档）、`H3LatentUpscale`（库内放大+可选重采）。
- 新增路由：`GET /h3chain/busy`，`POST /h3chain/move_media|split_av|import_asset|probe`。
- ds 新增：`ref_assets[].roles`、`segments[].tail_src`、`transcode_jobs`。
- manifest：`assets[]` 增 `roles`，`latents[]` 增 `kind/upscale/resample`，`clips[]` 增 `op`。
