# 全参考模式改写输出格式指南

> 本文件是官方英文规则 `minimaxh3_official_ref2v_prompt_writing.txt` 的**中文版**：
> 六段式结构、参考标签体系、保留标记、任务类型前缀逐条对应，
> **只有「正文用什么语言写」这一项不同** —— 英文版正文用英文，本版正文用中文。
> 骨架（字段名、标签、标记值、任务类型）仍然逐字英文。

本指南说明全参考模式下改写输出如何组织与撰写。

**六段正文一律用中文写。** 只有 `<d>` 里的对白 / 歌词，以及画面中可见的文字，
保留其原语言。骨架（六个段名、`<Subject N>` 等标签、`fully_preserved` 等标记值、
`[reference generation]` 等任务类型前缀）**逐字英文，不许翻译**。

**描述详细度：** `detailed_description` 要写得**尽可能详细、具体**。每个镜头都要明确交代
当前构图、主体外观与位置、环境与光照、动作与状态变化、运镜、当前声音，以及参考内容
**实际出现或生效的位置**。不要把它压缩成剧情摘要或参考关系清单。

> 镜头、运镜、说话人、对白与普通声音的基本格式与《视频提示词撰写指南（T2VA / I2VA / FL2VA / L2VA）》共用。
> 本指南只讲全参考模式特有的参考标签、分析小节与格式差异。

## 1. 整体结构

一份完整的改写输出由**六个小节**按下列顺序组成：

| 小节 | 作用 |
| --- | --- |
| `subject_definitions` | 定义被参考的内容及其参考标签 |
| `summary` | 概括任务类型、目标视频与主要参考关系 |
| `retention_analysis` | 说明参考内容如何被保留、迁移或复用 |
| `detailed_description` | 按播放顺序描述画面、动作、镜头、声音与对白 |
| `overall_soundscape` | 概括环境音与物理声音 |
| `non_diegetic_music` | 描述只有观众能听到的配乐 |

## 2. 参考标签与定义（`subject_definitions`）

全参考改写用**四类标签**标识参考内容的来源与作用：

| 标签 | 含义 |
| --- | --- |
| `<Subject N>` | 从参考素材中抽象出来的、可在目标视频里复用或修改的**可见内容** |
| `<Picture N>` | 被当作**具体目标帧**或分镜锚点使用的一张参考图 |
| `<Video N>` | 提供剪辑来源、续写起点或整片时序结构的参考视频 |
| `<Audio N>` | 被复制或参考的音频信号 |

> 一份内容一旦被分配了参考标签，它在 `subject_definitions`、`summary`、
> `retention_analysis`、`detailed_description` 与音频小节中**含义始终一致**。

`subject_definitions` 定义每一份**后续需要单独追踪**的参考内容，例如一个人物、一个环境、
一条源视频的结构或一条音轨。每一项**独占一行**，说明它的标签指什么、参考角色是什么、
需要跟随的主要特征有哪些；需要点明出处时，写出对应的源素材名。如果某个 `<Picture N>`
或 `<Video N>` 只是用来说明另一项参考内容的来源、后面不会再单独分析或使用，
就把它写进那一项的定义句里，**不要单独占一行**。`retention_analysis` 记录每一项参考内容
在哪里出现、是完全保留、部分保留、迁移还是复用。

### 2.1 `<Subject N>`

`<Subject N>` 用于可复用的可见内容，包括：

- 人物、动物或物体
- 场景、背景或环境
- 服装、道具、界面或视觉效果
- 风格、动作、表情或姿态

它代表一个**真的会在目标视频里被使用**的内容单元，而不是源文件本身。
一个 subject 可以由多份参考素材共同定义，一份参考素材也可以提供多个 subject。

```text
<Subject 1> 是 <Picture 1> 中的年轻女子，长深色头发，蓝色开衫，一条细银项链。
```

同一个 subject 来自多份素材时，把来源合并写出，并说明每份素材提供了什么：

```text
<Subject 1> 是那位女子，外貌来自 <Picture 1>，行走动作来自 <Video 1>。
```

### 2.2 `<Picture N>`

当**参考图本身**就是一个镜头的首帧、关键帧、尾帧、被编辑的关键帧或构图锚点时，
才为它单独写一行 `<Picture N>`：

```text
<Picture 2> 是 [Shot 1] 的首帧，画面中一名女子坐在咖啡馆窗边。
```

如果一张图只是用来定义角色、场景、服装或风格，**不要**为它单独建 picture 条目，
而是把这张图作为来源写进对应的 `<Subject N>` 定义句里。

当一张图充当分镜或镜头规划参考时，要写明它对应哪些镜头、提供什么规划信息：

```text
<Picture 3> 是 [Shot 1] 与 [Shot 2] 的分镜参考，定义了它们的视点、主体位置与镜头顺序。
```

### 2.3 `<Video N>`

`<Video N>` 只用于**整片级别**的关系，例如：

- 对一条原始视频做剪辑
- 从原始视频结尾继续
- 参考原始视频的运镜、切镜、节奏或时序结构

```text
<Video 1> 是目标视频剪辑所用的源视频。
```

如果一条参考视频里的某个人物、物体、场景、动作或效果被当作**可见内容**复用，
它仍然属于 `<Subject N>`。`<Video N>` 标识的是**素材或结构来源**，不替代 subject 标签。

### 2.4 `<Audio N>`

`<Audio N>` 代表一条独立音频素材，或一条参考视频中被启用的同步音轨。常见用途包括：

- 复制全部或部分音频信号
- 参考某段背景音乐的风格
- 参考某个说话人的音色与表达方式
- 使用原音频里的对白、歌词或音效
- 参考节拍、节奏或音频连续性

当某条 `<Audio N>` 明确对应目标视频中的某个说话人时，定义里**复用该说话人的全局编号**：
说话人已映射到某个已定义 subject 时写 `<Subject N> (Sx)`，否则用稳定的嗓音描述后接 `(Sx)`。
该编号来自目标视频的全局说话人顺序，**不在音频定义里另行分配或重新编号**。说话人编号规则见 5.4 节：

```text
<Audio 1> 是 <Subject 1> (S1) 的音色参考。
```

当一条音频素材承担多个角色时，用**一句自然的话**把角色都描述出来，不要额外拆出子小节。

### 2.5 同一参考视频的画面轨与音频轨

`<Video N>` 与 `<Audio N>` **各自独立编号**。每个序号只表示该标签在**自己这一类里**的顺序，
不编码两类之间的配对关系。因此同一条参考视频可能同时对应 `<Video 1>` 与 `<Audio 2>`；
序号不同并不妨碍它们来自同一份源素材。

一条普通参考视频**不会仅仅因为文件里带声音就产生 `<Audio N>`**。

`<Audio N>` 的定义**主要说明音频的作用**，不一定要点名它来自哪条 `<Video N>`。
只有为了消除出处歧义时才写出共同来源，例如：

```text
<Video 1> 是目标视频剪辑所用的源视频。
<Audio 2> 是 <Video 1> 的同步音轨，在目标视频中被复用。
```

## 3. `summary`

这一节用**一个简短的中文段落**概括目标视频及其参考关系。它以方括号包起来的**任务类型前缀**开头：

```text
[reference generation] ……
[video editing + reference generation + audio reuse] ……
```

按每份参考素材在目标视频里**实际扮演的角色**选择任务类型：

| 任务类型 | 何时使用 |
| --- | --- |
| `keyframe completion` | 某张图作为目标视频的首帧、关键帧、尾帧、被编辑的关键帧或其他具体帧锚点 |
| `reference generation` | 某张图 / 某条视频或音频为角色、场景、风格、动作、运镜、分镜等提供生成指导，但不作为具体帧、也不是被剪辑或续写的源视频 |
| `video editing` | 直接修改一条已有的源视频；对图片做编辑、或在两张静帧之间生成，都不属于这一类 |
| `video continuation` | 新内容从已有源视频继续、延长、接续或过渡而来 |
| `audio reuse` | 同一段音频信号被整体或部分复用 |
| `audio reference` | 不直接复制音频信号，只参考它的音乐风格、音色、对白或歌词内容、音效质感、节拍或连续性 |

一项任务满足多种关系时，用 ` + ` 连接任务类型，且**同一类型不重复**。例如从源视频续写、
同时用一张图作尾帧，写作 `[video continuation + keyframe completion]`；
剪辑源视频同时保留其原始音频，可写作 `[video editing + audio reuse]`。

**仅仅存在视频或音频，并不会自动产生对应的任务类型。** 如果一条参考视频只提供运镜、切镜或节奏，
它通常属于 `reference generation`。只有在这条视频**被直接剪辑或续写**时，才用
`video editing` 或 `video continuation`。

剪辑源视频时，如果它的原始音频仍然可闻，还要加上 `audio reuse`。
从源视频续写但没有直接复制音频信号、新音频只是延续原音轨的可闻特征时，用 `audio reference`。

summary 使用前面已定义的 `<Subject N>` / `<Picture N>` / `<Video N>` / `<Audio N>` 标签
来描述主要主体、镜头流与各参考素材的作用。**本小节不得引入新的参考标签。**

视频剪辑类任务，在任务类型前缀之后这样开头：

```text
目标视频是 <Video 1> 的剪辑版本。
```

## 4. `retention_analysis`

这一节说明每一项参考内容在目标视频中如何被保留、迁移、复制或参考。
**每个参考标签一行**，并保持 `subject_definitions` 里确立的含义。

### 4.1 可见内容

`<Subject N>` / `<Picture N>` / `<Video N>` 使用下列关系标记。这些标记是输出格式里
**固定的英文取值**：

| 关系标记 | 含义 |
| --- | --- |
| `fully_preserved` | 该参考内容被定义的角色被完全保留 |
| `partially_preserved` | 参考内容仍在使用，但某些已定义特征被改变或只部分保留 |
| `attribute_transfer` | 参考特征被迁移到另一个可识别的目标主体上 |
| `weak_reference` | 只保留风格、类别、构图或氛围上的宽泛相似 |

subject 条目：

```text
<Subject 1> (appears in [Shot 1], [Shot 3]): fully_preserved - 深色长发、蓝色开衫与细银项链都保留。
```

picture 条目：

```text
<Picture 2> ([Shot 1] first frame): fully_preserved - 构图、窗边位置与光线方向都保留。
```

video 结构条目：

```text
<Video 1> (cut and pacing structure): weak_reference - 只参考它的切镜节奏，不复用画面。
```

### 4.2 音频

`<Audio N>` 使用下列关系标记：

| 关系标记 | 含义 |
| --- | --- |
| `fully_copy` | 完整源音频作为目标视频的完整最终音轨 |
| `partially_copy` | 只复制时间轴上的一部分或选定的音频层，或在复制后加入、移除、替换了其他声音 |
| `reference` | 不直接复制信号，只参考音色、节奏、音乐风格、对白内容或声音质感 |
| `weak_reference` | 只保留类别或氛围上的宽泛相似 |

```text
<Audio 1>: fully_copy - <Audio 1> 被 1:1 复用为目标视频的完整最终音轨。
```

```text
<Audio 2>: reference - 目标说话人跟随 <Audio 2> 的音色与实测表达方式，不复制原始信号。
```

关系标记只能在该标签于 `subject_definitions` 里**已被定义的角色范围内**选择。
不要把目标视频里新增的动作、背景或剧情事件当成参考保真度的损失。

## 5. `detailed_description`

这是全参考改写的主体。它按目标视频的播放顺序**逐镜**描述画面、动作、声音与对白，
并在适用处插入参考标签。

### 5.1 基本格式

基本格式遵循《视频提示词撰写指南（T2VA / I2VA / FL2VA / L2VA）》：

- **正文用中文写。** 只有对白、歌词与画面中可见的文字保留原语言。
- `[Shot 1]` 标记开场镜头，**不带时间戳**。后续镜头用 `[Shot N] At MM:SS.mmm, ……` 标记切镜时间。
- 运镜写成当前镜头内**自然的中文语句**（运镜词表本身仍用英文逐字，见 4.3 节），
  需要时带上运动类型、幅度与速度。
- 发声源给稳定的 `(S1)` / `(S2)` 编号。对白与歌词写成 `<d>[语言] ……</d>`。
- 跨切镜的对白用 `<scenetrans>`，被片尾截断的语音用 `<cutoff>`，跨镜连续的音频用对应的连续性描述。

关于运镜词表、群体说话、画外音、跨切镜对白与画面可见文字的完整规则与范例，
见《视频提示词撰写指南（T2VA / I2VA / FL2VA / L2VA）》。

### 5.2 全参考模式的差异

| 维度 | T2VA | 全参考模式 |
| --- | --- | --- |
| 主体字段 | `integrated_multimodal_description` | `detailed_description` |
| 风格开场 | 写在 `[Shot 1]` 之后 | 在 `[Shot 1]` **之前**用一两句中文立住 |
| 参考信息 | 不使用全参考标签 | 在 `<Subject N>` / `<Picture N>` / `<Video N>` / `<Audio N>` **首次出现处**及其作用生效处插入 |
| 音频关系 | 描述目标视频自身的声音 | 在对应镜头或音频阶段引用 `<Audio N>`，并说明信号是被复制还是被参考 |

开场范例：

```text
目标视频是电影感、文学化的音乐录影带风格，光线柔和，色调略带去饱和。
[Shot 1] 场景从一条拥挤的城市街道开始……
[Shot 2] At 00:09.000, 镜头切到一个极特写……
```

生成类任务的 `detailed_description` 通常为 **350–500 个英文词**（中文口径约 500–750 字）。
对白密集的内容**优先把完整的口头时间轴放下**，而不是机械地凑字数。
剪辑类视频的描述随源视频复杂度伸缩，不必套用生成类任务的字数区间。
单镜**不会**自动就该写得更短；按各镜的信息量分配细节。

### 5.3 在镜头里使用参考标签

某个重要 `<Subject N>` **首次清晰出现**时，要在镜头中**实际可见的范围内**描述它的参考特征、
画面位置与当前动作。后续镜头继续沿用同一标签，**不再重新定义**它代表什么。

具体帧锚点用自然的说法：

```text
镜头从 <Picture 1> 开始
该镜头的关键帧对应 <Picture 2>
镜头落在 <Picture 3> 上结束
```

编辑或续写原始视频时，在源状态、结构或续写关系生效处自然地引用 `<Video N>`。
在音频关系生效的镜头或语义阶段引用 `<Audio N>`。

### 5.4 说话人、声源与对白

说话人编号与 `<d>` 的基本格式遵循 T2VA。被参考的主体**本人开口说话**时，
视觉参考标签与说话人编号**都要保留**：

```text
<Subject 2> (S1) 转向那名女子，说道：<d>[Chinese] 去年夏天我去了爷爷家。他提起过你。</d>
```

`<Subject N>` 标识被参考的主体，`(Sx)` 标识实际发声者。主体说话时写 `<Subject N> (Sx)`。
同一主体**画外**说话时，保持同样的写法并标为 `off-screen`。说话人不对应任何已定义 subject 时，
用稳定的嗓音描述后接 `(Sx)`。

当口头内容只是**被直接复用的 BGM 或完整音轨里的一个提示**，且没有人物、角色、旁白者
或其他独立人声源实际发出它时，用 `<Audio N>` 作为可闻来源，**不要凭空补一个 `(Sx)`**。
如果确有具体的人、角色、旁白者或其他独立人声源发出这段声音，就为那个来源分配并复用 `(Sx)`：

```text
当 <Audio 1> 唱到 <d>[English] I'm lonely lonely lonely lonely lonely I'm lonely</d> 时，
<Subject 1> 做出对应的手势，但不因此成为独立的发声源。
```

当参考音频里的对白、旁白或歌词被**直接复用**，或输入提示明确要求**重新演绎**它们时，
要在 `<d>` 里**逐字保留**源文本与原语言。听不清的片段写 `[unclear]`，**不许猜、不许改写**。
标点统一为表达句子所必需的基本书写标点，例如 `,` `.` `?` `!`；
去掉重复的波浪号、emoji、项目符号以及重复或装饰性标点。
完整的陈述、疑问与感叹句在 `</d>` 之前分别以 `.` `?` `!` 收尾。

只参考音色、节奏、情绪或表达方式时，**不要把参考音频里的原始台词带进目标视频**。

`(Sx)` 按目标视频中**实际发声事件的顺序**分配一次，并在 `detailed_description` 的每次
实际发声事件处复用对应编号；`subject_definitions` 里绑定到某个目标说话人的 `<Audio N>`
定义**也复用同一个 `(Sx)`**，但**绝不自行新分配**。`retention_analysis` 里**不要写 `(Sx)`**。
只存在于被直接复用的 BGM 或完整音轨里的口头提示用 `<Audio N>`；
由具体的人、角色、旁白者或其他独立人声源实际发出的声音用 `(Sx)`。

## 6. `overall_soundscape` 与 `non_diegetic_music`

这两个声音类别的定义遵循《视频提示词撰写指南（T2VA / I2VA / FL2VA / L2VA）》。

`overall_soundscape` 概括全片的环境音与物理声音。对白、演唱以及与某个镜头同步的声音事件
仍留在 `detailed_description` 里：

```text
overall_soundscape: 安静的室内房间底噪与低沉通风声贯穿全片。
```

`non_diegetic_music` 描述角色听不到、只有观众能听到的配乐。有配乐时，说明乐器、速度与力度发展：

```text
non_diegetic_music: 慢速克制的钢琴独奏，底下垫着持续的低音大提琴，全程没有渐强。
```

使用参考音频时，只在**与可闻层相符的那一节**里说明它的复制或参考关系：
环境音与音效属于 `overall_soundscape`，只有观众能听到的配乐属于 `non_diegetic_music`。
同一段音频同时提供两类内容时，在两节里分别描述对应关系：

```text
overall_soundscape: 从 <Audio 1> 复制来的环境层在目标视频中贯穿始终。
non_diegetic_music: <Audio 2> 被直接复用为完整的观众专属配乐。
```
