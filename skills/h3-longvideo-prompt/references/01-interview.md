# 01 · 提问：把需求问清再动手

## 提问方式（硬规则）

- **用结构化提问工具**（带选项的那种），不要甩一大段文字让用户自己组织回答。
- **一次问完**。分多轮挤牙膏是最让人烦的；把所有缺的信息一次列全（最多 4 个问题）。
- **选项说人话**，不许露黑话：说「图里的画面直接动起来」而不是「I2VA」；说「脸和衣服按图1长」而不是「fully_preserved」。
- **一题只问一个维度**。机制（有没有参考图）和职责（图用来干什么）是两个正交问题，不许塞进同一组选项。
- 每题都要留自定义输入口；选项按推荐度排序，推荐的注明为什么。
- 用户答「随便 / 你定 / 都行」→ **给一个推荐值并注明，直接往下走**，不要再追问同一个问题。
- **最多问两轮**。第二轮只补第一轮没答清的。

## 必须问清的七件事

### 1. 时长与段数（决定后面一切）
- 总时长多少？想切成几段？（没想法就按每段 8–10 秒帮你定）
- ⚠️ H3 单段硬上限 **4–15 秒**。总时长 ÷ 段数必须落在这个区间：30 秒 → 3–4 段；60 秒 → 5–8 段；120 秒 → 10–15 段。
- 用户给了总时长没给段数 → 你按 8–10 秒/段算好段数，并**告诉他这个换算结果**。

### 2. 参考图（无条件要问 —— 见 `05-reference-images.md`）
- 已经有没有参考图（角色 / 场景 / 道具 / 风格）？
- 没有的话：要不要生成？生成什么？几张？

### 3. 内容骨架
- 谁（人物：外貌、服装、年龄、音色）？在哪？干什么？**结局是什么**？
- 有没有必须出现的关键道具或台词（原话）？

### 4. 段与段的衔接
- 是**一条连续的故事**（默认，`独立镜头：否`），还是每段各拍各的（跳转 / 蒙太奇，`独立镜头：是`）？
- 连续的话：中间有没有时间跳跃或场景切换的节点？

### 5. 视听风格
- 写实 / 动画 / CG 三维 / 定格？（影响质感描述）
- 色调与光线（冷 / 暖 / 高对比 / 柔）？颗粒感？
- 镜头偏好：手持 / 稳定器 / 固定机位 / 航拍？

### 6. 对白
- 有没有台词？谁说的？说什么（要原话）？什么语言？
- 没有对白就明确「全程无对白」——**这会阻止模型自己加台词**。

### 7. 声音
- 要不要环境音（什么环境）？要不要配乐？
- 不要配乐就明确「无配乐」——成品里写 `N/A`。

## 问完之后

把答案整理成一份**简短的确认摘要**回给用户（总时长 / 段数 / 每段秒数 / 模式 / 参考图方案 / 风格 / 有无对白配乐），一句话请求确认，然后进 `02-expand.md`。

用户回答含糊（"来点氛围感"）时：**给 2–3 个候选方向让他选**，不要自己猜一个就往下写。
