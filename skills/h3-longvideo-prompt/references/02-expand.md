# 02 · 扩写：一句话 → 每段剧本

**这一步只管内容，不管格式。** 不要输出 `integrated_multimodal_description` 这类英文字段名，不要 `[Shot N] At MM:SS.mmm` 骨架，不要 JSON。格式是第 3 步的事。

**这一步不设创作上限。** 扩写是你的主场——把用户给的那一句话长成能拍出来的画面，是你的工作，不是"越忠实越好"的抄写。下面的规则不是**限制**，是**如何把话说清楚**的方法；除了「不许改用户点名要保的东西」（见「唯一红线」），其余地方你想加什么加什么。

## 两套运行环境，两套起手式

| 环境 | 怎么开工 |
|---|---|
| **线上 agent**（对话里服务用户） | **先问清需求再动笔**。先把要问的一次问完（见 `01-interview.md`），拿到答复后**在用户需求的基础上自由发挥**——不设风格、事件、细节上的自我审查 |
| **本地**（挂在导演台上跑） | **直接自由发挥**。不需要先确认，用户在段卡里给了什么你就往满里写，把节点能力用足 |

## 先出一份全片清单（多段时必做）

| 项 | 内容 |
|---|---|
| 整片一句话 | 全片概括 |
| 人物 | 每个角色的固定特征：外貌 / 服装 / 年龄 / 音色（跨段不许变） |
| 一致性 | 不许走样的东西：光线方向、道具、服化道、时间天气 |
| 分段 | 每段一句话 logline + 承接方式 + 时长 |

**每段写剧本时都要带上这份清单**，否则人物会在段与段之间变脸。

## 每段五个动作

1. **定秒数**：写「时长：N 秒」。长动作取大值，单点情绪取小值。
2. **排节拍**：按播放顺序拆成一串连续可见动作。每拍写清谁、在哪、做什么、镜头怎么走、什么声音。
3. **补执行细节**（你的价值所在）：用户只写"她回头笑了"，你要补出环境光怎么落、手在干什么、呼吸节奏、周围什么声音、镜头从哪推到哪。
4. **写对白**：角色真要说话才写，写成 `角色名：「台词」`。**用户给的原话一字不改**。
5. **写声音**：环境音、动作音、要不要配乐，简单交代，**不写情绪形容词**。

## 密度：节拍与字数

约**每 3 秒一个节拍**，每拍至少 2 句（一句画面动作、一句镜头声音）。

| 段时长 | 节拍数 | 剧本大致字数 |
|---|---|---|
| 4–5 秒 | 2 | 120–200 |
| 6–8 秒 | 2–3 | 180–330 |
| 9–11 秒 | 3–4 | 270–450 |
| 12–15 秒 | 4–5 | 360–600 |

**宁可把动作写慢写透，也不要一句话概括完然后停在原地。**

- 反面：「她走进房间，环顾四周，然后笑了。」—— 2 秒的内容硬撑 10 秒。
- 正面：推门 → 光从门缝扫过她的脸 → 木地板上的两声脚步 → 她停在门口让眼睛适应光线 → 手指在门框上停一下 → 才抬头。

对白按 **4.3 字/秒** 估时：10 秒段的台词总量别超过 40 字，超了就剪。

## 段间衔接（**最容易翻车的地方**）

默认 `Standalone: no`。此时**下一段必须承接上一段**，五件事逐条对齐：

| 维度 | 要求 |
|---|---|
| 位置 | 上段结束在哪，下段就从那开始（或交代清楚移动过程） |
| 时间 | 连续。有跳跃必须写明（"三小时后"） |
| 动作 | 上段没做完的动作，下段接着做（她伸手去够 → 下段接住） |
| 情绪 | 延续或合理演变，不能凭空重置 |
| 外观环境 | 服装、光线方向、天气、道具位置保持一致（清单里的「一致性」就是干这个的） |

写法上：**段首交代承接，但不要重复介绍已经交代过的静态信息**——不要每段都重新写一遍"她穿着灰卫衣"，那是浪费字数，也会让模型以为换了造型。

写 `Standalone: yes` 的段（跳转 / 闪回 / 蒙太奇）时，虽然不接上一段的画面，仍要**说明跳转关系**（"三天后" / "与此同时" / "回忆里"），否则观众会断线。

## 唯一红线：用户点名要保的东西

这是**唯一**的创作约束，其余全部放开：

- **不许改**：用户点名的人物、关键道具、用户给的原话台词（一字不改）、用户指定的结局走向。
- **不许加**：新的人物关系（用户没提的血亲 / 恋人）、替换用户给的结局。
- 除此之外——机位、光线、材质、微动作、呼吸、环境声源、道具陈设、次角、群演、天气变化、构图层次、镜头运动的花样，**都可以加，往满里加**。

**意图含糊时的做法**：线上先按上面问清楚；问不到（本地跑、用户没回）就**选一个最具体、最有戏的方向写到底**，不要给多个版本让用户挑。给多个版本 = 把创作责任推回用户。

## 输出骨架（形如即可）

````
时长：10 秒

镜头一（0–3 秒）：……
镜头二（3–7 秒）：……
镜头三（7–10 秒）：……

台词：林晚：「……」
环境声：……
背景音乐：无
````

⚠️ 最后三个词是**特意避开**「对白 / 环境音 / 配乐」的——后三个是总提示词格式的段级标签名，写在行首会被解析器吃掉。
