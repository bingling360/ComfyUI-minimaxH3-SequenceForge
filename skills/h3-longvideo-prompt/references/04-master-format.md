# 04 · 总提示词框格式（最终拼装）

最终交付的文本要被 SequenceForge 的「总提示词框」解析并分配到各段。它只认下面这套语法。

## 完整骨架

```
【段1】
时长：10
独立镜头：否

提示词：
integrated_multimodal_description: [Shot 1] …

overall_soundscape: …

non_diegetic_music: N/A

【段2】
时长：10
独立镜头：否

提示词：
…

【完】
```

- **段头** `【段N】`：N 可省，别名也认（`【段落1】`/`【第1段】`/`【1段】`）。**必须独占一行。**
- **`【完】`**（或 `【END】`/`【结束】`）：其后的内容不参与解析。
- **段级标签只有三个**，其余一律是正文。

## 三个段级标签

| 标签 | 取值 | 语义 |
|---|---|---|
| `时长：N` | 正数秒 | 本段时长，必须与前一步分配的一致 |
| `独立镜头：是\|否` | `是/独立/断链/开/true/yes` = 是；`否/连续/关/false/no` = 否 | **是** = 本段**不**自动引用上段尾帧（跳转 / 闪回 / 蒙太奇）；**否** = 连续接上段 |
| `提示词：` | 官方格式正文 | 真正进模型的内容。标签独占一行，正文从下一行开始 |

## ⚠️ 三个标签必须写在 `提示词：` 之前

一旦出现过任一个「正文类」标签（`提示词` / `场景` / `角色` / `环境音` / `配乐` / `意图` / `剧本`），后面的 `时长：` `独立镜头：` `参考：` 就**不再是标签**：

- `时长` / `独立镜头` 会变成**正文的一部分**（正文里写「时长：12 秒」不会被误当段时长）；
- **`参考：` 会连同那一行被吞进正文、跟着进模型，而且不给任何提示**（已实测复现）。

所以拼装顺序固定为：段头 → 时长 → 独立镜头 → `提示词：` → 正文。

## 废弃标签：一律不要写

`场景：` `角色：` `环境音：` `配乐：` `意图：` `剧本：` `参考：`

这些是旧版的段级字段，现在**只有提示词正文进模型**。场景 / 角色 / 环境音 / 配乐的正确位置是正文里的官方三字段（或六字段）。

写了不会报错，但内容**不会生效**、也不会进正文，只会在解析时收到一条「已忽略」提示。

## 资产引用：正文里的 `@素材名`

**正文是唯一真相。** 本段挂哪些素材，完全由正文里 `@素材名` 的出现序列决定，没有第二份清单。

```
提示词：
integrated_multimodal_description: [Shot 1] 中景，@女主 站在雨夜的窄巷口，@雨夜窄巷 的霓虹在积水里拉出长影。

overall_soundscape: 雨声持续。

non_diegetic_music: N/A
```

匹配规则：`@` 前一个字符不能是字母/数字/下划线（防 `a@b.com`）；按素材名**从长到短**取最长命中；按首次出现顺序收集，重复引用会重复计数。

## 其他会踩的坑

| 症状 | 原因 |
|---|---|
| 整篇被当成一段 | 段头没独占一行（从聊天界面复制时换行被吃掉）。一般会自动重分行，仍失败就检查段头写法 |
| 三字段糊成一坨 | 粘贴时字段之间的空行被删了——**空行必须保留** |
| 段时长没被认 | 「时长：」写在了 `提示词：` 之后 |
| 素材没挂上 | 引用写成了「参考：」标签，而不是正文里的 `@素材名` |

段级标签是**单行元数据**：写完它就归位了，紧跟其后的裸正文归「提示词」，不会被并进别的字段。
