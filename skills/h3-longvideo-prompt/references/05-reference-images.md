# 05 · 参考图：两条分支

**改参考图会改整条片子的长相，所以必须在第 1 步就问清，不能等写完提示词再补。**

---

## 分支 A：用户已经给了参考图

**默认规则：每一段都要用到。**

- 只有用户**明确说某段不用**（"第 2 段是纯空镜，不用参考图"），那一段才不写引用。
- 该角色/场景在画面里的段，就一定要引用，否则模型没有理由保持它一致。
- 引用策略：

| 图的作用 | 哪些段要引用 |
|---|---|
| **角色**（脸 / 发型 / 服装） | 该角色**出场或可能出场的每一段**——这是维持身份不漂移的唯一手段 |
| **场景**（环境 / 光线 / 陈设） | 该场景出现的每一段（通常是从头到尾） |
| **道具 / 产品** | 该道具特写或参与关键动作的段 |
| **风格**（色调 / 质感） | 可作为全片风格参考，在每段引用；但它不作为具体帧锚 |

- 素材名用素材库里的**完整名字**（含扩展名）最稳，例如 `@女主_正面.png`。

### 引用写在正文的哪里（按模式分）

| 模式 | 写法 |
|---|---|
| **base**（T2VA / I2VA / FL2VA / L2VA） | 直接写进 `integrated_multimodal_description` 正文，形如 `@女主_正面.png` |
| **Ref2VA** | **只**写在 `subject_definitions` 的定义行；`summary` 及以后一律用 `<Subject N>` 指代，**正文里不许出现 `@`** |

Ref2VA 的正确形态（图里的内容 → `<Subject N>`；图本身 → 定义行里的 `@`）：

```
subject_definitions:
<Subject 1> is the content defined by <Picture 1>, the reference image "女主_正面.png".
<Subject 2> is the content defined by <Picture 2>, the reference image "高原雪山_广角.png".

detailed_description: [Shot 1] <Subject 1> stands at the edge of the ridge; the snow line of <Subject 2> cuts the frame ...
```

⚠️ **用户报过的 bug**：多参时把 `@女主_正面.png` 写进了 `detailed_description`，结果正文里冒出图片引用。**Ref2VA 下 `@` 只能待在定义行。**

## 分支 B：用户没给参考图

### B-1 先问三件事

1. **要不要生成参考图？**（不要 → 直接进第 2 步，按 T2VA / I2VA 走）
2. **生成什么？**（角色 / 场景 / 道具 / 风格，可多选）
3. **要几张？**（给建议：单主角 + 单场景 = 2 张起步；多角色或多场景按数量加）

### B-2 给出「参考图提示词附录」

**每张图给两样东西：一条图像生成提示词 + 它在视频里的作用。**

格式：

```
【参考图 1】建议命名：女主_正面.png
作用：钉主角身份（脸、发型、服装）——全片每一段都引用
图像提示词：25 岁女性，藏族，深棕肤色，黑长发编成两条辫子垂在胸前，
穿深红色藏袍、外披灰白氆氇；正面半身，视线平视镜头，表情中性；
简洁浅灰背景，柔和均匀的顶光；画幅 3:4；写实摄影质感，皮肤保留真实纹理。

【参考图 2】建议命名：高原雪山_广角.png
作用：定开场场景（山体轮廓、雪线高度、天空色调）——第 1 段引用
图像提示词：清晨高原，连绵雪山主峰占据画面右侧三分之二，山脊线锐利，
山脚有裸露的灰褐色岩层；广角远景，无人物；左上角低角度侧逆光，
雪面呈冷白偏蓝；画面干净无云；画幅 16:9；写实，高细节。
```

**图像提示词的写法**（这是给图像模型的，不要用 H3 的 `[Shot N]` 骨架）：

- 主体：外貌 / 服装 / 年龄 / 体态 / 材质，写具体的**颜色和形状**
- 视角与构图：正面半身 / 全身 / 三分侧 / 广角远景 / 特写
- 背景：简洁纯色（做角色参考）或真实环境（做场景参考）
- 光照：方向 + 软硬 + 色温
- 画幅：角色 3:4、场景 16:9
- 角色图要点：**中性表情、视线平视、单人不遮挡**——表情太强会污染后续所有段
- 场景图要点：**无人物或人物极小**，明确光源方向
- 风格图要点：写清色调、质感、颗粒、参考媒介

### B-3 给出「初版提示词」

把参考图按其**作用**写进各段的引用位置，**此时图还没生成**：

- 引用写在哪按模式走（见上面「引用写在正文的哪里」）：base 写正文，Ref2VA 写 `subject_definitions` 定义行；
- 图片文件先用建议命名占位（例如 `@女主_正面.png`）；
- 每段仍要完整走完扩写 + 格式优化，长度、段间衔接全部到位；
- 明确告诉用户：「这是初版，等你把上面几张图生成好，再发我一次，我会按实际画面校正后给最终版」。

**停下来等用户。**

### B-4 用户生成完之后：读图 → 校正 → 最终版

- **宿主能读图** → 实际读一遍，按真实画面校正：
  - 图中的人物特征（发色、服装颜色与细节、体态）与剧本不一致 → **以图为准**改正文描述
  - 图里出现了剧本没写但对画面有用的元素（背景建筑、纹样、道具）→ 判断是否纳入
  - 图与剧本冲突到影响剧情（比如画成了另一个人）→ **回头问用户**，不要硬写
  - 引用名换成用户实际的文件名（定义行里的 `@`、以及素材库里的名字都对齐）
- **读不到图** → 请用户用一两句话回执（"图1：黑发红衣，正面半身"），按回执校正。
- 校正只动**与图相关的描述**，剧情结构、段时长、段间衔接不动。

---

## 附：为什么默认「每段都引用」

H3 的参考机制靠正文里的引用生效：某段不写引用，模型就没有依据保持人物 / 场景一致，那一帧开始人物就可能变脸。
所以默认全段引用，把「不用」当成需要用户**显式说明**的例外。

后端把正文里的 `@素材名` 序列按**首次出现顺序**压实成官方的 `<Subject N>` / `<Picture N>` 标签，所以引用顺序不影响结果——但**位置**影响（Ref2VA 只在定义行）。
