# 07 · 交付前自检

**逐项打勾，缺一项就回去改，不要带着问题交付。** 最好再通读一遍成品，把自己当读者看一遍。

## A. 结构（总提示词框能不能解析）

- [ ] 每个段头 `[Segment N]` 都**独占一行**，序号从 1 连续
- [ ] 段数是用户要的段数（不多不少）
- [ ] 末尾有 `[END]`
- [ ] **整篇没有中文标签**（`【段1】` / `时长：` / `独立镜头：` / `提示词：` / `【完】` 一个都不许出现）——中文只允许在 `<d>[语言] …</d>` 对白里
- [ ] 段级标签**只有** `Duration / Standalone / Prompt` 三个，没写任何废弃标签（`Scene:` / `Character:` / `Ambience:` / `Music:` / `Intent:` / `Script:` / `Reference:` 及其中文版）
- [ ] 三个标签**都写在 `Prompt:` 之前**
- [ ] `Duration: N` 的值与前面分配的秒数逐段一致
- [ ] `Standalone:` 逐段都显式写了（`yes` 或 `no`，不许省——省了 = 该字段不动、继承旧值）
- [ ] `Standalone` 只在跳转 / 闪回 / 蒙太奇时才写 `yes`，其余写 `no`
- [ ] 字段之间的空行保留着（没被压扁）

## B. 每段正文（格式对不对）

- [ ] 字段集正确：常规是三字段，全参考六段式；字段名**逐字**正确、顺序对、一个不多一个不少
- [ ] `[Shot 1]` 开头且**不带时间戳**；后续 `[Shot N] At MM:SS.mmm` 时间严格递增且不超过本段时长
- [ ] 对白形如 `(S1) …说道：<d>[Chinese] 原文</d>`，**原文一字未改**；不出声的角色没给编号
- [ ] 环境音在 `overall_soundscape` 里、没混入对白；无配乐时 `non_diegetic_music: N/A`
- [ ] 对齐指令（I2VA / FL2VA / L2VA）在最前面整句照抄，只替换了 N 与 S.SS
- [ ] **正文里一个 `@素材名` 都没有**（Ref2VA 模式下尤其要看）——`@` 只允许出现在 `subject_definitions` 的定义行
- [ ] `<Subject N>` / `<Picture N>` / `<Video N>` / `<Audio N>` 的用法与官方语义一致：可复用内容用 `<Subject N>`，具体帧锚才用 `<Picture N>`
- [ ] `retention_analysis` 里的标记：可见内容用 `fully_preserved` 那套，音频用 `fully_copy` 那套，**没混用**

## C. 长度（配不配得上时长）

- [ ] 逐段核对：主描述字数落在 **时长 × 20–40 字** 区间内
- [ ] 对白总量 ≤ **时长 × 4.3 字**（10 秒段 ≤ 40 字）
- [ ] 没有为了凑字数重复描述同一个动作

## D. 段间关联（最容易翻车）

- [ ] 相邻两段逐对检查：**位置、时间、动作、情绪、外观**能不能接上
- [ ] 上段结尾的状态，下段开头有承接（不是重新开始）
- [ ] 静态信息（服装 / 场景）没有每段重复介绍
- [ ] 标了 `Standalone: yes` 的段，写明了跳转关系（"三小时后" / "回忆里"）

## E. 参考素材（图 / 视频 / 音频）

- [ ] 用户给了图 → **每段**都引用了（除非用户明确说某段不用）
- [ ] **base 模式**：引用写在正文里、用 `@素材名`，且用的是真实文件名
- [ ] **Ref2VA 模式**：引用写在 `subject_definitions` 定义行；正文里只有标签
- [ ] 该角色出场的段都引用了角色图；没有漏
- [ ] **视频参考**每条一条 `<Video N>` 定义行，正文里用 `<Video N>` 指代
- [ ] **音频参考**每条一条 `<Audio N>` 定义行，保留标记走 `fully_copy` / `partially_copy` / `reference` / `weak_reference`
- [ ] 用户没给图 → 附录里每张图都有「图像提示词 + 作用 + 建议命名」
- [ ] 走的是「初版 → 等图 → 读图校正 → 最终版」的流程，没有跳过校正

## F. 最终交付形态

- [ ] 只输出那一份多段文本，没有夹带解释、markdown 标题或代码围栏
- [ ] 直接整段复制粘贴进总提示词框就能「解析并分配」，无需用户手工改任何一处
