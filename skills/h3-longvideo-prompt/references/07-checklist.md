# 07 · 交付前自检

**逐项打勾，缺一项就回去改，不要带着问题交付。** 最好再通读一遍成品，把自己当读者看一遍。

## A. 结构（总提示词框能不能解析）

- [ ] 每个段头 `【段N】` 都**独占一行**，序号从 1 连续
- [ ] 段数是用户要的段数（不多不少）
- [ ] 末尾有 `【完】`
- [ ] 段级标签**只有** `时长 / 独立镜头 / 提示词` 三个，没写任何废弃标签（场景 / 角色 / 环境音 / 配乐 / 意图 / 剧本 / 参考）
- [ ] 三个标签**都写在 `提示词：` 之前**
- [ ] `时长：N` 的值与前面分配的秒数逐段一致
- [ ] `独立镜头` 只在跳转 / 闪回 / 蒙太奇时才写「是」，其余写「否」
- [ ] 字段之间的空行保留着（没被压扁）

## B. 每段正文（格式对不对）

- [ ] 字段集正确：常规是三字段，全参考六段式；字段名**逐字**正确、顺序对、一个不多一个不少
- [ ] `[Shot 1]` 开头且**不带时间戳**；后续 `[Shot N] At MM:SS.mmm` 时间严格递增且不超过本段时长
- [ ] 对白形如 `(S1) …说道：<d>[Chinese] 原文</d>`，**原文一字未改**；不出声的角色没给编号
- [ ] 环境音在 `overall_soundscape` 里、没混入对白；无配乐时 `non_diegetic_music: N/A`
- [ ] 对齐指令（I2VA / FL2VA / L2VA）在最前面整句照抄，只替换了 N 与 S.SS

## C. 长度（配不配得上时长）

- [ ] 逐段核对：主描述字数落在 **时长 × 20–40 字** 区间内
- [ ] 对白总量 ≤ **时长 × 4.3 字**（10 秒段 ≤ 40 字）
- [ ] 没有为了凑字数重复描述同一个动作

## D. 段间关联（最容易翻车）

- [ ] 相邻两段逐对检查：**位置、时间、动作、情绪、外观**能不能接上
- [ ] 上段结尾的状态，下段开头有承接（不是重新开始）
- [ ] 静态信息（服装 / 场景）没有每段重复介绍
- [ ] 标了 `独立镜头：是` 的段，写明了跳转关系（"三小时后" / "回忆里"）

## E. 参考图

- [ ] 用户给了图 → **每段**都引用了（除非用户明确说某段不用）
- [ ] 引用写在正文里、用 `@素材名`，且用的是真实文件名
- [ ] 该角色出场的段都引用了角色图；没有漏
- [ ] 用户没给图 → 附录里每张图都有「图像提示词 + 作用 + 建议命名」
- [ ] 走的是「初版 → 等图 → 读图校正 → 最终版」的流程，没有跳过校正

## F. 最终交付形态

- [ ] 只输出那一份多段文本，没有夹带解释、markdown 标题或代码围栏
- [ ] 直接整段复制粘贴进总提示词框就能「解析并分配」，无需用户手工改任何一处
