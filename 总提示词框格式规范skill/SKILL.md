# 导演台 总提示词 格式规范

你写的是给「📋 总提示词」框粘的文本，不是散文。
**前端 `parseMasterPrompt` 会按 八标签 + 段头 自动切分成多段**，后端 `H3SeamlessChainSampler` 按段发往 H3 采样。
所以这是机器解析的契约文本——格式错就直接塌缩成 1 段或字段错位，提交前必须自检。

## 总结构（必须遵守）

```
【段1】
…八标签字段…
【段2】
…八标签字段…
……
【完】
（参考素材建议块，可省；其后内容不参与解析）
```

- **段头独占一行**：匹配 `【段N】` / `【段落N】` / `【第N段】` 任意一种。序号可省但建议写明，方便人核对与跳过/重排。
- **`【完】` 必写**：否则建议块内容会被灌进末段「提示词」主体，导致解析走样。
- **在聊天 UI / 会按 markdown 渲染的界面，整篇用 ` ``` ` 围栏包裹**——解析器忽略围栏行本身，并且保住段内换行（不围栏则粘到「📋 总提示词」会塌缩成 1 段）。
- **有空行 / 围栏行 / `【完】` 之后的行**：全部不参与解析（建议块安全区）。
- **聊天 UI 渲染塌缩时**会自动 `mpReflow` 重分行（兜底）；但别依赖它，**写时主动加换行 + 围栏**最稳。

## 八标签字段

字段名是契约的一部分（前端硬匹配这 8 个固定名）：

| 字段 | JS 内部 key | 推荐 | 规则摘要 |
|---|---|---|---|
| `场景` | scene | 推荐 | 媒介+质感+调色+时代+光照；同剧情各段**逐字复用**——弱编码器漂移 = 段间接缝跳变；省略时沿用前段 |
| `角色` | character | 推荐 | 外观+服饰+位置；同剧情各段**逐字复用**，绝不写「他/她」；多角色用 `；` 分隔，各自完整；省略时沿用前段 |
| `环境音` | soundscape | 否 | 每个声音单独点名 + 进入时间（中文写法「2秒处」）；无声音整行省略 |
| `配乐` | music | 否 | 乐器+节奏+动态+进入时间；无配乐整行省略 |
| `时长` | seconds | 推荐 | 数字（秒，**正数**），**必等于该段时间线最后一片的止点**（5-10 常用，可写小数 6.5）；省略或非正数 → warning 并忽略 |
| `独立镜头` | unlink | 否 | **YES** = 是 / 独立 / 断链 / 开 / true / yes（任一）；**NO** = 否 / 连续 / 关 / false / no（任一）；其他值 → warning 并忽略。跳转/闪回/蒙太奇段写 `是`；连续叙事省略；**段1 通常不写（无前段可锚；parser 不强制）** |
| `参考` | refs | 否 | 已有素材标签用 `，` / `,` / `、` / `；` / `;` 任一或混用分隔；多参模式才写；首帧模式不写（与首帧互斥）；空值省略此行 |
| `提示词` | main | 推荐 | 本段时间线 + 运镜 + 动作 + 对白；**可多行续行**；省略时该段 prompts 为空（沿用前段） |

> **空值语义**（按字段类型区分，由解析器实际行为反过来）
> - **文本字段**（`场景` / `角色` / `环境音` / `配乐` / `提示词`）：写空 → 设为 `""`（应用时覆盖）；不写 → `undefined`（沿用前段，不覆盖）
> - **数值字段**（`时长`）：写空 / 写负数 / 写非数字 → warning 并忽略（字段为 `undefined`）
> - **布尔字段**（`独立镜头`）：写空 / 写非常用同义词 → warning 并忽略（字段为 `undefined`）
> - **数组字段**（`参考`）：写空 → 解析为 `[]`；`undefined` 时不覆盖

> ⚠️ **参考标签运行时过滤**：`applyMasterPrompt` 只采纳「素材与参考」面板已上传的标签，未上传的会被剔除并产生 note（提示先上传素材获得标签）。

**冒号写法**：全角「：」或半角「:」均可，**前后空格均可**（解析器正则 `\s*[：:]\s*` 容忍任意空白）。

```
【段1】
场景：日系动画风格，黄昏的教室，暖橘侧光斜照课桌，长影子
角色：16岁短发少女，蓝色水手服，白色领巾，坐在靠窗倒数第二排
环境音：翻书声持续，2秒处笔尖划纸
配乐：钢琴独奏慢板，1秒进入
时长：5
参考：角色1
提示词：[0s-3s] 固定机位，少女低头写字。[3s-5s] 她抬头望向窗外，轻声说「今天也早点回去吧。」
```

## `提示词` 字段里怎么写时间线

- **切片格式**严格 `[起s-止s]`：方括号、小写 s、**无空格**；每片一句。
- **从 0s 开始、连续不重叠**；末片止点 = 同段 `时长` 的值。
- 一句一个动作，**≤20 字**；禁从句嵌套、禁比喻、禁四字成语堆叠。
- **正向措辞**——"保持静止" 优于 "不要移动"；否定只保留最关键的一条（"画面干净无字幕无水印"）。
- **字面文本**：`招牌写着「食堂」`——直角引号原文，让编码器照抄。
- **对白**：「」直角引号，每段最多一两句。
- **一个运镜词**：推近 / 拉远 / 左摇 / 右摇 / 上摇 / 俯拍 / 仰拍 / 侧跟 / 正跟 / 环绕 / 固定机位；每段一个，相邻段换方向（推→拉）形成节奏。

## 与官方 h3-prompt-writing 的兼容

后端 `H3SeamlessChainSampler` 会自动把八标签组装成官方 H3 字段，**用户无需手写**：

| 你写 | 后端组装 |
|---|---|
| `提示词` 主体 | `integrated_multimodal_description:` |
| 「……」对白 | `<d>[中文]</d>` |
| `环境音` | `overall_soundscape:` |
| `配乐` | `non_diegetic_music:` |
| `参考` 列表 | 段首自动注入 `subject_definitions:`（Picture / Video / Audio 三类编号） |

**已写官方字段的用户直贴**：含 `integrated_multimodal_description:` / `overall_soundscape:` / `detailed_description:` 任一即识别为官方格式，**原样直发**不重包装——两种格式可并存于同一套段内（高级用法）。

## 完整示例（必须能被 `parseMasterPrompt` 干净解析：3 段 / 零警告）

```
【段1】
场景：日系动画风格，黄昏的教室，暖橘色侧光斜照课桌，长影子
角色：16岁短发少女，蓝色水手服，白色领巾，坐在靠窗倒数第二排
环境音：翻书声持续，2秒处笔尖划纸
配乐：钢琴独奏慢板，1秒进入，克制
时长：5
参考：角色1
提示词：[0s-3s] 固定机位，少女低头写字。[3s-5s] 她停下笔，抬头望向窗外，轻声说「今天也早点回去吧。」

【段2】
场景：日系动画风格，黄昏的校门口，逆光剪影，樱树叶子被风吹动
角色：16岁短发少女，蓝色水手服，白色领巾；同班男生，深蓝校服背书包，并肩站在台阶下
环境音：自行车铃声，1秒处；晚风拂叶持续
配乐：钢琴加入弦乐长音，3秒进入，渐强
时长：6
参考：角色1
提示词：[0s-3s] 镜头缓慢拉远，两人并肩走出校门。[3s-6s] 少女回头朝教学楼方向挥手。

【段3】
场景：日系动画风格，黄昏的河堤路，天色转深蓝，路灯刚亮
角色：16岁短发少女，蓝色水手服，白色领巾；同班男生，深蓝校服背书包，并肩缓行
环境音：河水声持续，脚步踩碎石，4秒处男生开口
时长：6
独立镜头：是
提示词：[0s-4s] 侧跟机位随两人移动。[4s-6s] 男生说「明天见」，少女点头微笑，镜头摇向河面倒影收尾。

【完】
参考素材建议
1. 名称：角色1（角色设定图）
   用途：段1-3 少女形象一致性锚定（画面身份靠参考图，提示词只管场景和动作）
   画图提示词：角色三视图设定图，日系动画风格，16岁短发少女，蓝色水手服，
   白色领巾，米色书包，正面/侧面/背面三姿势站立，纯浅灰背景，柔和均匀光照，
   线条清晰，无文字
2. 名称：风格板（场景基调图）
   用途：全链黄昏色调统一
   画图提示词：黄昏教室空镜，日系动画风格，暖橘色侧光斜照木质课桌，地面长影子，
   无人物，无文字
备注：男生出场两段，未单设参考图（次要角色靠文字描述）；如一致性不足再补「角色2」。
```

## 字段语法骨架（`<…>` 替换为自己的内容；骨架块会触发两条 warning ——「时长」`<秒数>` → 「不是有效秒数」，「独立镜头」`是/否` → 「应为 是/否」；`check_skill_prompt_format.js` 显式豁免这两条，骨架块仅作字段名兜底参考）

```
【段<N>】
场景：<风格契约：媒介+质感+调色板+时代+光照>
角色：<外观+服饰+位置>
环境音：<声音+进入时间>
配乐：<乐器+节奏+动态+进入时间>
时长：<秒数>
独立镜头：是/否
参考：<素材标签列表>
提示词：[<起s-止s>] <动作>。<对白>。[<起s-止s>] …
```

## 自检清单（交稿前逐项核对）

- [ ] 每段都有 `时长`（推荐），且等于该段时间线最后一片的止点
- [ ] 时间线从 0s 开始、切片连续不重叠、格式 `[Ns-Ms]`（小写 s、无空格）
- [ ] 同剧情各段 `场景` / `角色` 措辞逐字复用；写「独立镜头：是」的段写全 场景+角色
- [ ] 「独立镜头：是」只出现在跳转/闪回/蒙太奇段；段1 通常不写
- [ ] `参考` 分隔用 `，` / `,` / `、` / `；` / `;` 任一；标签必须先在「素材与参考」面板上传
- [ ] 末段后有 `【完】`；chat UI 整篇用 ` ``` ` 围栏
- [ ] 字段行就是字段行，无 markdown 装饰（不要 `**` `*` 等）
- [ ] 对白全部「」直角引号，每段不超过两句；无成语、无比喻、无否定堆叠
- [ ] `node tools/check_skill_prompt_format.js` 通过
